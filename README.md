Kingdom Crushers is a lightweight yet beautiful open world MMO, inspired by ROTMG. To emphasize how lightweight it is, the game server itself is running on a 10$/mo Digital Ocean Ubuntu server!
Try it out now at kingdomcrushers.io, or download it from the play store: https://play.google.com/store/apps/details?id=com.williamqm.mmorelam
You can also check out the live updating wiki at wiki.kingdomcrushers.io

Though the player base has died down, it is still a fun 100% original experience with loads of content.
